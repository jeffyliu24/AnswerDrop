# 九月 API 用量简报

> 以下数字均为演示数据，可直接用于体验 AnswerDrop。

## 一句话结论

本月共处理 **12,000 次请求**，其中 **11,820 次成功**，成功率为 **98.5%**。

| 指标       |   数值 |
| ---------- | -----: |
| 总请求数   | 12,000 |
| 成功请求数 | 11,820 |
| 失败请求数 |    180 |

成功率的计算方法是 $11{,}820 / 12{,}000 = 98.5\%$。

## 复核方法

```python
total = 12000
successful = 11820
print(f"成功率：{successful / total:.1%}")
```
