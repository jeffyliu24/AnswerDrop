# Reporting security issues

Please report vulnerabilities privately through GitHub's **Report a vulnerability** option on the official repository once it is published. If that option is unavailable, open an issue asking for a private contact method without posting exploit details or secrets. Include affected version, impact, reproduction steps, and a proposed fix if you have one.

Supported version: the latest v0.1.x release. The [security model](docs/security.md) describes the intended trust boundaries and current limits. Scanner findings are advisory and cannot guarantee that a document contains no secrets.
